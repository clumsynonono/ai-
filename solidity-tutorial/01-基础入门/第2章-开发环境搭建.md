# 第2章：开发环境搭建

本章将指导你搭建完整的 Solidity 开发环境。我们会介绍多种工具，从最简单的在线 IDE 到专业的本地开发框架。

## 2.1 Remix IDE（推荐新手使用）

### 什么是 Remix？
**Remix** 是一个基于浏览器的 Solidity IDE，无需安装即可使用。

### 优点
- ✅ 零配置，打开即用
- ✅ 集成编译器和调试器
- ✅ 内置测试环境
- ✅ 支持插件扩展

### 使用步骤

#### 1. 访问 Remix
打开浏览器，访问：https://remix.ethereum.org/

#### 2. 创建新文件
```
左侧面板 → File Explorer → 点击"新建文件"图标
文件名：HelloWorld.sol
```

#### 3. 编写代码
```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract HelloWorld {
    string public message = "Hello, Remix!";

    function setMessage(string memory _newMessage) public {
        message = _newMessage;
    }
}
```

#### 4. 编译合约
```
左侧面板 → Solidity Compiler
选择编译器版本：0.8.0+
点击 "Compile HelloWorld.sol"
```

#### 5. 部署合约
```
左侧面板 → Deploy & Run Transactions
Environment: Remix VM (Cancun) - 这是本地模拟环境
点击 "Deploy"
```

#### 6. 与合约交互
```
部署后，在 Deployed Contracts 下：
- 点击 "message" 查看当前消息
- 输入新消息到 "setMessage" 并点击按钮更新
```

### Remix 界面导览
```
┌─────────────────────────────────────────┐
│  File Explorer  │   编辑器区域           │
│  - contracts/   │   (代码编写)           │

```

## 2.2 MetaMask 钱包配置

### 安装 MetaMask

1. **下载浏览器插件**
   - Chrome/Brave: [Chrome Web Store](https://chrome.google.com/webstore)
   - Firefox: [Firefox Add-ons](https://addons.mozilla.org/)

2. **创建钱包**
   ```
   打开 MetaMask → 创建钱包
   设置密码 → 备份助记词（12个单词）
   ⚠️ 务必安全保管助记词，不要泄露给任何人！
   ```

### 添加测试网络

#### Sepolia 测试网（推荐）
```
网络名称：Sepolia
RPC URL：https://sepolia.infura.io/v3/YOUR_INFURA_KEY
链 ID：11155111
货币符号：SepoliaETH
区块浏览器：https://sepolia.etherscan.io/
```

#### 快速添加
访问 [Chainlist](https://chainlist.org/)，搜索 "Sepolia"，点击 "Add to MetaMask"

### 获取测试币

1. **Sepolia Faucet**
   - https://sepoliafaucet.com/
   - https://www.alchemy.com/faucets/ethereum-sepolia

2. **使用方法**
   ```
   复制你的 MetaMask 地址
   粘贴到 Faucet 网站
   完成验证（可能需要登录）
   等待几分钟收到测试 ETH
   ```

## 2.3 Hardhat 开发框架

Hardhat 是专业开发者首选的本地开发框架。

### 环境要求
- Node.js 18+
- npm 或 yarn

### 安装步骤

#### 1. 创建项目目录
```bash
mkdir my-solidity-project
cd my-solidity-project
npm init -y
```

#### 2. 安装 Hardhat
```bash
npm install --save-dev hardhat
```

#### 3. 初始化项目
```bash
npx hardhat init
```
选择：`Create a JavaScript project`

#### 4. 项目结构
```
my-solidity-project/
├── contracts/          # Solidity 合约文件
│   └── Lock.sol
├── scripts/           # 部署脚本
│   └── deploy.js
├── test/              # 测试文件
│   └── Lock.js
├── hardhat.config.js  # Hardhat 配置
└── package.json
```

#### 5. 安装依赖
```bash
npm install --save-dev @nomicfoundation/hardhat-toolbox
```

### 基本命令

#### 编译合约
```bash
npx hardhat compile
```

#### 运行测试
```bash
npx hardhat test
```

#### 启动本地节点
```bash
npx hardhat node
```

#### 部署到本地网络
```bash
npx hardhat run scripts/deploy.js --network localhost
```

### Hardhat 配置示例

```javascript
// hardhat.config.js
require("@nomicfoundation/hardhat-toolbox");

module.exports = {
  solidity: "0.8.19",
  networks: {
    sepolia: {
      url: "https://sepolia.infura.io/v3/YOUR_INFURA_KEY",
      accounts: ["YOUR_PRIVATE_KEY"] // ⚠️ 不要提交到 Git！
    }
  },
  etherscan: {
    apiKey: "YOUR_ETHERSCAN_API_KEY"
  }
};
```

⚠️ **安全提示**：使用环境变量存储私钥
```javascript
require("dotenv").config();

module.exports = {
  networks: {
    sepolia: {
      url: process.env.SEPOLIA_RPC_URL,
      accounts: [process.env.PRIVATE_KEY]
    }
  }
};
```

创建 `.env` 文件：
```
SEPOLIA_RPC_URL=https://sepolia.infura.io/v3/YOUR_INFURA_KEY
PRIVATE_KEY=your_private_key_here
```

## 2.4 其他有用的工具

### OpenZeppelin Contracts
安全、经过审计的合约库
```bash
npm install @openzeppelin/contracts
```

使用示例：
```solidity
import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract MyToken is ERC20 {
    constructor() ERC20("MyToken", "MTK") {
        _mint(msg.sender, 1000000 * 10**18);
    }
}
```

### Ethers.js
与以太坊交互的 JavaScript 库
```bash
npm install ethers
```

### Etherscan
区块链浏览器，用于：
- 查看交易
- 验证合约代码
- 查看 Gas 价格
- 主网：https://etherscan.io/
- Sepolia：https://sepolia.etherscan.io/

### Tenderly
调试和监控工具
- 交易模拟
- 合约验证
- 实时监控
- https://tenderly.co/

## 2.5 开发环境对比

| 工具 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| **Remix** | 学习、快速原型 | 零配置、易用 | 功能有限 |
| **Hardhat** | 专业开发 | 强大、灵活 | 学习曲线陡 |
| **Truffle** | 企业项目 | 成熟稳定 | 较重量级 |
| **Foundry** | 高级开发者 | 极快速度 | Solidity 测试 |

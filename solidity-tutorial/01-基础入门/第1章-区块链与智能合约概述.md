# 第1章：区块链与智能合约概述

## 1.1 什么是区块链？

区块链是一种**分布式账本技术**，具有以下核心特征：

### 核心特性
- **去中心化**：没有单一控制点，由网络节点共同维护
- **不可篡改**：数据一旦写入，几乎无法修改
- **透明性**：所有交易公开可查
- **安全性**：密码学保护数据安全

### 工作原理
```
交易发起 → 广播到网络 → 节点验证 → 打包成区块 → 添加到链上 → 全网同步
```

## 1.2 以太坊生态系统

以太坊是一个**可编程的区块链平台**，允许开发者部署智能合约。

### 关键组件
1. **以太币 (ETH)**：以太坊的原生加密货币
2. **EVM (以太坊虚拟机)**：执行智能合约的运行环境
3. **Gas**：衡量计算资源消耗的单位
4. **账户系统**：
   - 外部账户 (EOA)：由私钥控制
   - 合约账户：由代码控制

### 以太坊网络类型
- **主网 (Mainnet)**：真实的生产环境
- **测试网 (Testnet)**：
  - Sepolia（推荐使用）
  - Goerli
  - Rinkeby（已弃用）
- **本地网络**：Ganache, Hardhat Network

## 1.3 什么是智能合约？

智能合约是**部署在区块链上的自动执行程序**。

### 特点
✅ **自动执行**：条件满足时自动运行
✅ **不可篡改**：部署后代码无法修改
✅ **去信任**：不需要中介即可执行
✅ **透明可验证**：代码公开可审计

### 应用场景
- 💰 **DeFi (去中心化金融)**：借贷、交易所、稳定币
- 🎨 **NFT (非同质化代币)**：数字艺术品、游戏道具
- 🗳️ **DAO (去中心化自治组织)**：链上治理
- 📜 **供应链管理**：溯源、防伪
- 🎮 **区块链游戏**：GameFi, Play-to-Earn

### 智能合约示例（概念）
```solidity
// 一个简单的投票合约概念
合约 投票系统 {
    如果 (投票者有资格) {
        记录投票
        更新计数
        触发事件
    }
}
```

## 1.4 Gas 费用机制

在以太坊上，每个操作都需要消耗 **Gas**。

### Gas 相关概念
- **Gas Limit**：愿意为交易支付的最大 Gas 数量
- **Gas Price**：每单位 Gas 的价格（以 Gwei 计）
- **交易费用** = Gas Used × Gas Price

### Gas 计算示例
```
简单转账：21,000 Gas
部署合约：200,000 - 1,000,000+ Gas
调用函数：根据复杂度从几千到几十万 Gas

如果 Gas Price = 50 Gwei
部署合约费用 ≈ 500,000 × 50 = 25,000,000 Gwei = 0.025 ETH
```

### 优化 Gas 的重要性
- 💸 **节省成本**：Gas 费可能很高，尤其是主网
- ⚡ **提升效率**：优化代码减少计算量
- 🎯 **用户体验**：低费用吸引更多用户

## 1.5 Solidity 简介

**Solidity** 是以太坊的主要智能合约编程语言。

### 语言特点
- 静态类型语言
- 面向对象（支持继承）
- 语法类似 JavaScript/C++
- 专为 EVM 设计

### Solidity 代码结构
```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract MyFirstContract {
    // 状态变量
    string public greeting = "Hello, Solidity!";

    // 函数
    function setGreeting(string memory _newGreeting) public {
        greeting = _newGreeting;
    }
}
```

### 版本说明
- 当前稳定版本：0.8.x
- 主要改进：
  - 内置溢出检查
  - 更好的错误处理
  - 自定义错误节省 Gas

## 1.6 开发者需要知道的安全问题

⚠️ **智能合约一旦部署就无法修改**，因此安全至关重要！

### 常见安全问题
1. **重入攻击 (Reentrancy)**
2. **整数溢出/下溢**（0.8.0+ 自动检查）
3. **访问控制不当**
4. **随机数可预测性**
5. **未检查的外部调用**

### 安全最佳实践
✅ 使用最新版本的 Solidity
✅ 采用成熟的库（如 OpenZeppelin）
✅ 进行完整的测试
✅ 代码审计
✅ 使用 Checks-Effects-Interactions 模式
